# Bakieva Chat | Вступить в чат

Telegram-бот для продажи 30-дневной подписки на закрытый канал и чат Bakieva Chat.

## Что реализовано

- главное меню строго из 5 пунктов;
- приветствие из ТЗ;
- обязательное принятие оферты, политики конфиденциальности, согласия на обработку данных и условий подписки/возврата;
- Kaspi Pay по ссылке `https://pay.kaspi.kz/pay/byqjwvz7`;
- доступ **не выдаётся по нажатию «Я оплатил»** — заявка уходит администратору, который подтверждает её только после проверки фактического поступления в Kaspi Pay;
- после подтверждения создаются одноразовые ссылки в закрытый канал и чат;
- подписка на 30 дней;
- напоминание не более чем за 3 дня до окончания;
- автоматический отзыв доступа после окончания;
- кнопка «Вернуться в Bakieva Chat»;
- opt-out из рассылок;
- админ-команды для статистики, выдачи, продления, удаления, цены, рассылок и изменения текстов/материалов без нового деплоя;
- PostgreSQL;
- `/healthz` (процесс и БД) и `/readyz` (готовность poller и Telegram-доступа к платным направлениям).
- Instagram автоответчик по комментариям с отправкой сообщения в Direct;
- публикация Instagram Reels из Telegram-админки: видео → подпись → правило → Direct → публикация → автоматическая привязка Media ID.

## Почему подтверждение Kaspi сейчас ручное

Обычная Kaspi Pay ссылка открывает удалённую оплату, но сама по себе не предоставляет этому боту достоверный webhook о конкретной оплате. Для PDF-фискального чека требуется подтверждение данных на официальной странице Kaspi; если она недоступна, бот не активирует подписку по одному лишь тексту PDF. Поэтому выдавать доступ сразу после кнопки «Я оплатил» небезопасно.

Текущая схема: клиент платит → нажимает «Я оплатил» → администратор сверяет реальное поступление в Kaspi Pay → нажимает «Подтвердить оплату» → бот автоматически выдаёт доступ.

Для полностью автоматического подтверждения нужен отдельный платёжный API/webhook или подключённый эквайринг-провайдер.

## Переменные окружения

Скопируйте `.env.example` и заполните:

- `BOT_TOKEN`
- `DATABASE_URL`
- `ADMIN_IDS` — Telegram ID администраторов через запятую
- `PAID_CHANNEL_ID` — ID закрытого канала (`-1004476014410`, указан владельцем)
- `PAID_CHAT_ID` — старый ID чата для существующих legacy-потоков; не используется при выдаче нового платного доступа
- `PAID_MAIN_CHAT_ID` — ID группы, куда отправляется приглашение после оплаты (`-1004333394152`, Болталка, по уточнению владельца); также доступна привязка командой `/bind_main_chat` в группе
- `TALK_CHAT_ID` — ID Болталки (`-1004333394152`); существующие приглашения и участники Болталки обрабатываются отдельно от платных персональных ссылок
- `KASPI_MERCHANT_BIN` — 12 цифр БИН получателя для проверки чека
- `OFFER_URL`
- `PRIVACY_URL`
- `DATA_CONSENT_URL`
- `SUBSCRIPTION_TERMS_URL`
- при наличии: `TRIAL_LESSON_URL`, `FREE_CHANNEL_URL`
- для Instagram: `META_APP_ID`, `META_APP_SECRET`, `META_WEBHOOK_VERIFY_TOKEN`, `INSTAGRAM_ACCESS_TOKEN`, `INSTAGRAM_IG_USER_ID`, `META_GRAPH_VERSION`
- для публикации Reels: `PUBLIC_BASE_URL` необязателен на Railway, если доступен `RAILWAY_PUBLIC_DOMAIN`

Kaspi и номер поддержки уже имеют значения по умолчанию:

- `KASPI_PAY_URL=https://pay.kaspi.kz/pay/byqjwvz7`
- `SUPPORT_PHONE=+77712841932`

## Права бота

Добавьте бота администратором в платный канал и платный чат. Нужны права создавать пригласительные ссылки и удалять участников.

## Запуск

```bash
npm install
npm run build
npm start
```

Для Railway используйте Node.js 22+, PostgreSQL и перечисленные переменные окружения. Оставьте Railway healthcheck на `/healthz`: новый контейнер получает Telegram poller lock после остановки старого. `/readyz` отдельно проверяет DB, poller, scheduler, ID и права бота в канале и Болталке; до получения lock он вернёт 503. Диагностика и повторная выдача доступны в `/admin`; пользователь может запросить свои ссылки командой `/access`. Подробнее: `docs/production-review.md`.

## Администрирование

```text
/admin
/grant TELEGRAM_ID DAYS
/extend TELEGRAM_ID DAYS
/revoke TELEGRAM_ID
/price 5000
/set about новый текст
/set content новый текст
/set trial_url https://...
/set free_channel_url https://...
/broadcast текст рассылки
```

Пользователь должен хотя бы один раз нажать `/start`, прежде чем администратор сможет выдать ему доступ вручную.

В разделе `/admin → Instagram автоответчик → Новый Reels` маркетолог может загрузить видео, указать подпись, выбрать триггер комментариев и текст Direct. После публикации бот получает Instagram Media ID и включает правило автоматически.

При использовании стандартного облачного Telegram Bot API исходный файл Reels должен быть не больше 20 МБ, потому что `getFile` не скачивает более крупные файлы.

## Важно про Telegram

Telegram Bot API не позволяет боту принудительно добавить произвольного пользователя в приватный канал или группу. После подтверждённой оплаты бот создаёт персональные одноразовые ссылки на вступление. Это сохраняет требование: получить ссылку на платный чат можно только после подтверждённой оплаты.
