# Bakieva Chat | Вступить в чат

Telegram-бот для продажи 30-дневной подписки на закрытый канал и чат Bakieva Chat.

## Что реализовано

- главное меню строго из 5 пунктов;
- приветствие из ТЗ;
- обязательное принятие оферты, политики конфиденциальности, согласия на обработку данных и условий подписки/возврата;
- Kaspi Pay по ссылке `https://pay.kaspi.kz/pay/byqjwvz7`;
- доступ **не выдаётся по нажатию «Я оплатил»** — заявка уходит администратору, который подтверждает её только после проверки фактического поступления в Kaspi Pay;
- после подтверждения создаются одноразовые ссылки в закрытый канал и чат;
- подписка на 30 дней;
- напоминание не более чем за 3 дня до окончания;
- автоматический отзыв доступа после окончания;
- кнопка «Вернуться в Bakieva Chat»;
- opt-out из рассылок;
- админ-команды для статистики, выдачи, продления, удаления, цены и рассылок;
- PostgreSQL;
- `/healthz` и `/readyz` для Railway.

## Почему подтверждение Kaspi сейчас ручное

Обычная Kaspi Pay ссылка открывает удалённую оплату, но сама по себе не предоставляет этому боту достоверный webhook о конкретной оплате. Поэтому выдавать доступ сразу после кнопки «Я оплатил» небезопасно.

Текущая схема: клиент платит → нажимает «Я оплатил» → администратор сверяет реальное поступление в Kaspi Pay → нажимает «Подтвердить оплату» → бот автоматически выдаёт доступ.

Для полностью автоматического подтверждения нужен отдельный платёжный API/webhook или подключённый эквайринг-провайдер.

## Переменные окружения

Скопируйте `.env.example` и заполните:

- `BOT_TOKEN`
- `DATABASE_URL`
- `ADMIN_IDS` — Telegram ID администраторов через запятую
- `PAID_CHANNEL_ID` — ID закрытого канала
- `PAID_CHAT_ID` — ID закрытого чата
- `OFFER_URL`
- `PRIVACY_URL`
- `DATA_CONSENT_URL`
- `SUBSCRIPTION_TERMS_URL`
- при наличии: `TRIAL_LESSON_URL`, `FREE_CHANNEL_URL`

Kaspi и номер поддержки уже имеют значения по умолчанию:

- `KASPI_PAY_URL=https://pay.kaspi.kz/pay/byqjwvz7`
- `SUPPORT_PHONE=+77712841932`

## Права бота

Добавьте бота администратором в платный канал и платный чат. Нужны права создавать пригласительные ссылки и удалять участников.

## Запуск

```bash
npm install
npm run build
npm start
```

Для Railway используйте Node.js 22+, PostgreSQL и перечисленные переменные окружения.

## Администрирование

```text
/admin
/grant TELEGRAM_ID DAYS
/extend TELEGRAM_ID DAYS
/revoke TELEGRAM_ID
/price 5000
/broadcast текст рассылки
```

Пользователь должен хотя бы один раз нажать `/start`, прежде чем администратор сможет выдать ему доступ вручную.

## Важно про Telegram

Telegram Bot API не позволяет боту принудительно добавить произвольного пользователя в приватный канал или группу. После подтверждённой оплаты бот создаёт персональные одноразовые ссылки на вступление. Это сохраняет требование: получить ссылку на платный чат можно только после подтверждённой оплаты.
